# Models

Generated by `python ml_pipeline/train.py`.

| File | Committed? | Role |
| --- | --- | --- |
| `forecast_model.joblib` | No (binary) | Selected sklearn model + feature list |
| `model_metadata.json` | Yes | Real MAE / RMSE / MAPE and split details |
| `feature_list.json` | Yes | Target and input column names |

Retrain locally:

```powershell
python ml_pipeline/train.py
python ml_pipeline/evaluate.py
```

Do not edit `model_metadata.json` by hand. Those numbers must come from the training script.
